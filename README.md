# portfolio

Personal portfolio site built with [SvelteKit](https://svelte.dev/docs/kit) and deployed on Vercel.

## Development

```bash
npm install
npm run dev
```

## Building

```bash
npm run build    # outputs a Vercel build via @sveltejs/adapter-vercel
npm run preview  # preview the production build locally
npm run check    # type-check and validate Svelte components
```

All routes are prerendered (`src/routes/+layout.ts`).
